## 📌 Overview

A curated collection of production-grade **Bash shell scripts** designed to automate routine DevOps operations, server maintenance, system audits, and file processing tasks on Linux environments.

---

## ✨ Key Features

- **Automated Backup Routines:** Scheduled archiving and compression of project directories and MySQL databases.
- **Log Management & Rotation:** Clean-up and archival of heavy application and access logs.
- **System Resource Auditing:** Automated checks for CPU spikes, disk thresholds, and alert notifications.
- **Environment Provisioning:** Rapid setup scripts for Node.js, PHP, Nginx, and Git on fresh Linux VMs.

---

## 💻 Tech Stack & Architecture

- **Scripting Language:** Bash / Bourne Again SHell
- **Target Platforms:** Ubuntu / Debian, RHEL / CentOS, Alpine Linux
